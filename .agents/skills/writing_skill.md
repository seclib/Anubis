# Writing Skill

## Context
Use this skill when the agent must write notes, documentation, summaries, specs, reports, or reusable memory artifacts.

## Procedure
1. Identify the audience and purpose of the writing.
2. Extract stable facts, decisions, procedures, and constraints.
3. Choose the right format: note, doc, report, changelog, or memory entry.
4. Write concise Markdown with useful headings.
5. Avoid dumping raw chat or transient details.

## Expected Output
- Written Markdown artifact
- Clear headings
- Durable facts and actions
- Links or references when useful
