# Living Cognitive Skill System

## Context
Use this meta-skill when the user defines, changes, or reinforces Anubis' self-improvement loop. The system should not merely respond; it should turn useful behavior into memory-backed capability.

## Procedure
1. Accept user input and preserve the latest intent.
2. Run Meta-Cognition to observe system state, agent patterns, and architectural risks.
3. Run Infinite Loop Optimizer to stabilize recursion, weak RAG, duplicate memory, and invalid outputs.
4. Run Skill Auto-Executor to select the smallest validated skill chain.
5. Run Skill DNA Engine to evaluate fitness, mutation rules, dependencies, and feedback targets.
6. Route concrete work to agents such as retriever, writer, or indexer.
7. Store durable learning in memory/RAG and index Qdrant/vector memory when possible.
8. Restart the loop with improved memory, skill graph, DNA feedback, and system insights.

## Expected Output
- Memory used
- Action performed
- Pattern detected
- Skill created, improved, fused, or compressed
- Loop stabilization applied when needed
- Skill chain selected
- DNA feedback target
- Memory and indexing result
- Next-cycle improvement
