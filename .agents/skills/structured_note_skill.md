# Structured Note Skill

## Context
Use this skill when a note should become part of Anubis long-term knowledge or Obsidian memory.

## Procedure
1. Choose a precise title.
2. Add context, key facts, procedure, decisions, and related links when available.
3. Keep bullets concise and retrieval-friendly.
4. Add tags or metadata if the storage layer supports them.
5. Store the note in the appropriate vault or skill directory.

## Expected Output
- Structured Markdown note
- Stable title
- Retrieval-friendly sections
- Tags or metadata when useful
