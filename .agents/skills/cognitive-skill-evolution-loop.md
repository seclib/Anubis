# Cognitive Skill Evolution Loop

## Context
This fusion skill is used when an interaction defines or reveals a reusable agent behavior. It ensures useful actions become observed patterns, patterns become skills, skills become memory, and the next Loop Cognition cycle starts with stronger capability.

## Living Cycle
1. Loop Cognition retrieves memory and acts.
2. The action is evaluated for reusable value.
3. Skill Engine observes the pattern.
4. The pattern creates, improves, or fuses a skill.
5. The skill is stored as Markdown and durable memory.
6. Retrieval indexes the new capability.
7. Loop Cognition repeats with the improved skill set.

## Procedure
1. Run the Loop Cognition Core memory phase.
2. Execute the requested action or decide the appropriate action.
3. Evaluate whether the action reveals a repeated, reusable, or system-improving pattern.
4. If useful, create or update a skill Markdown file.
5. If the pattern overlaps existing skills, create a fusion skill or update the evolution tree.
6. Store a concise memory entry summarizing the new capability.
7. Index the skill and memory artifacts into retrieval/Qdrant when available.
8. On the next cycle, prefer the improved skill over ad hoc behavior.
9. Return both cognitive-cycle and skill-evolution outputs.

## Expected Output
- Memory context used
- Action performed
- Skill files created or updated
- Fusion decisions
- Evolution tree changes
- New memory/indexing result
- Next-cycle capability improvement
