# Summarization Skill

## Context
Use this skill when the agent needs a short summary for memory, status reporting, handoff, or future retrieval.

## Procedure
1. Identify the source material and summary purpose.
2. Preserve decisions, constraints, actions, outcomes, and reusable lessons.
3. Drop transient chatter and redundant detail.
4. Use concise bullets or short paragraphs.
5. Include open questions or verification status when relevant.

## Expected Output
- Compact summary
- Key decisions/actions
- Reusable lessons
- Verification or uncertainty notes
