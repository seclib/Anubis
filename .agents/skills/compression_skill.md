# Compression Skill

## Context
Use this skill when memory contains duplicates, scattered variants, or long histories that should become a canonical principle.

## Procedure
1. Retrieve related memories and notes.
2. Group duplicates, variants, and superseded details.
3. Extract the stable principle, decision, or workflow.
4. Write a concise canonical memory.
5. Update the evolution tree or related links if the compression affects skills.
6. Prefer traceability over deleting useful history.

## Expected Output
- Compressed principle or workflow
- Superseded/merged source list
- Updated note or memory artifact
- Indexing result
