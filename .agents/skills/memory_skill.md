# Memory Skill

## Context
Use this skill when the interaction produces reusable knowledge, user preferences, project decisions, constraints, or procedures.

## Procedure
1. Decide whether the information is durable and worth storing.
2. Reject small talk, duplicates, transient state, and low-value details.
3. Convert accepted knowledge into concise structured Markdown.
4. Store it in Hermes/Obsidian or the configured memory system.
5. Index memory into vector retrieval/Qdrant when possible.
6. Verify that retrieval can find the stored knowledge.

## Expected Output
- Memory eligibility decision
- Stored memory artifact or reason skipped
- Indexing result
- Retrieval verification when possible
