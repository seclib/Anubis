# Hermes Active Memory Management

## Principle
Hermes should actively manage memory because memory is finite and quality matters more than quantity.

## De-prioritize
- Outdated information
- Duplicated content
- Low-relevance memories
- Temporary states

## Keep
- High-value reusable knowledge
- Stable user preferences
- Project decisions and constraints
- Canonical principles that improve future reasoning

## Management Rules
- Prefer canonical abstractions over repeated raw details.
- Mark superseded memories instead of letting duplicates compete.
- Keep traceability through links to consolidated notes.
- Retrieve high-priority memory first.
