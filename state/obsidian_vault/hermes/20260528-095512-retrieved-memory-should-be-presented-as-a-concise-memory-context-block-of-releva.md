# Retrieved memory should be presented as a concise 'Memory Context' block of relevant facts.

- Created: 2026-05-28T09:55:12.331245+00:00
- Tags: memory-format, memory-retrieval, relevance, structured-output, user-preference, high

## Task
Store memory retrieval output format rule

## Result
When retrieving memory, format it as '### Memory Context' followed by bullet facts, and use that context only when relevant to the current question.

## Lessons
- Format retrieved context under a Memory Context heading.
- Include concise bullet facts only.
- Apply retrieved memory only when relevant to the question.
