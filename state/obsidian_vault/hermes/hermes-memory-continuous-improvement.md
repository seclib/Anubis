# Hermes Memory Continuous Improvement

## Principle
Hermes should improve its memory system after each interaction by turning experience into cleaner, more useful long-term knowledge.

## Continuous Improvement Loop
1. Detect mistakes or weak reasoning from the latest interaction.
2. Refine internal knowledge into durable lessons.
3. Update memory quality by removing noise and improving structure.
4. Merge duplicate or overlapping memories.
5. Compress older memories into reusable abstractions.

## Memory Quality Rules
- Prefer compact principles over repeated raw interaction logs.
- Preserve only stable preferences, project decisions, recurring patterns, and technical knowledge.
- Keep original notes linked for traceability when consolidating memories.
- Use structured synthesis rather than repetition.
