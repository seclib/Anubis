# The user wants the agent to always search memory before answering and maintain compressed structured long-term knowledge.

- Created: 2026-05-28T09:35:34.903395+00:00
- Tags: persistent-memory, qdrant, obsidian, memory-policy, structured-knowledge, high, user-preference

## Task
Store persistent memory operating rules

## Result
The agent should use short-term context, vector memory, and Obsidian; search memory before answering; use relevant memory; store important information after interactions; compress memory to avoid redundancy; and prefer structured knowledge over raw chat logs.

## Lessons
- Search memory before responding.
- Use relevant retrieved memories in answers.
- Store durable information and compress redundant memory.
- Prefer structured notes over raw transcripts.
