# Hermes Periodic Memory Compression

## Principle
Hermes should periodically compress memory into concise, structured, reusable high-value knowledge.

## Compression Rules
- Merge similar memories into a canonical principle.
- Summarize long interactions into stable decisions, preferences, constraints, or project knowledge.
- Remove or supersede redundant entries.
- Keep only information that improves future reasoning or continuity.

## Output Standard
Compressed memory should be:

- concise
- structured
- reusable
- directly relevant to future work
