# Memory Output Format Preference

## Summary
The user wants memory extraction results to be formatted as short, structured memory entries.

## Preferred Format
Each memory entry should include:

- `memory`: a short sentence describing the durable fact or preference
- `tags`: keywords that make the memory easy to retrieve
- `importance`: `low`, `medium`, or `high`
- `category`: `user`, `project`, `technical`, or `insight`

## Use Case
Apply this format when extracting long-term memory from an interaction.

The output should focus on reusable knowledge, not transient conversation details.
