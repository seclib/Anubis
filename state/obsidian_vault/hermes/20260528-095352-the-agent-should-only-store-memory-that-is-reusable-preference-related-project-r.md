# The agent should only store memory that is reusable, preference-related, project-related, or a decision/constraint.

- Created: 2026-05-28T09:53:52.085238+00:00
- Tags: memory-policy, storage-filter, deduplication, user-preference, constraint, high

## Task
Store memory eligibility rule

## Result
Only store information that is reusable in future conversations, defines a preference or habit, belongs to an ongoing project, or represents a decision or constraint. Do not store greetings, small talk, duplicate information, or irrelevant context.

## Lessons
- Reject greetings, small talk, duplicate information, and irrelevant context as memory.
- Accept durable preferences, habits, ongoing project facts, decisions, and constraints.
