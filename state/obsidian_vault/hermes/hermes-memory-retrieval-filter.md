# Hermes Memory Retrieval Filter

## Principle
Memory retrieval should be concise, relevant, and high-confidence.

## Return Only
- Relevant facts
- High-confidence memories
- Semantically similar past interactions

## Output Format
### Memory Context
- fact 1
- fact 2
- fact 3

## Exclude
- Source labels and scores
- Low-confidence matches
- Irrelevant memories
- Raw memory dumps
