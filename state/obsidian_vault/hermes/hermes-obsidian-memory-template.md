# Hermes Obsidian Memory Template

## Principle
Obsidian memory notes should be concise, structured, and grouped into stable retrieval categories.

## Required Format
# Memory - [DATE]

## Key facts
- ...

## User preferences
- ...

## Projects
- ...

## Insights
- ...

## Rules
- Summarize durable knowledge instead of dumping raw chat.
- Keep each note concise and easy to scan.
- Put each memory under the most relevant section.
- Prefer this canonical format over older daily-memory layouts.
