# Anubis combines Loop Cognition and Skill Evolution into a living self-improving system.

- Created: 2026-06-01T06:06:02.190828+00:00
- Tags: living-system, loop-cognition, skill-evolution, self-improvement, memory, skills, high

## Task
Encode living cognitive skill system

## Result
Updated cognitive-skill-evolution-loop.md, added living-cognitive-skill-system.md, and linked the meta-skill in evolution-tree.md. The loop is: cognition retrieves memory and acts, useful action is detected, Skill Engine observes the pattern, creates or improves a skill, stores it in memory, indexes it, then the next cognition loop starts with better capability.

## Lessons
- Useful actions should be evaluated as candidate reusable capabilities.
- Skill Engine should observe patterns after action, not only from explicit requests.
- Created or improved skills must be stored as Markdown memory and indexed for the next Loop Cognition cycle.
- The next cycle should prefer retrieved skills over ad hoc behavior.
