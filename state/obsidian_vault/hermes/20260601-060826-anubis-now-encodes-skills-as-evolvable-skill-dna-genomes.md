## Lessons
- Each skill can be represented as SKILL_DNA with id, purpose, triggers, inputs, steps, outputs, dependencies, mutation rules, and fitness score.
- Skill mutation should change triggers, steps, dependencies, or outputs to improve performance.
- Crossover fuses compatible skill genomes into hybrids.
- Fitness combines utility, usage frequency, precision, and cost; strong skills replicate, weak skills mutate, merge, or retire.
