# Obsidian memory notes should be structured markdown grouped by topic or date, summarized, and linked to related notes.

- Created: 2026-05-28T09:54:32.369534+00:00
- Tags: obsidian, markdown, memory-format, daily-note, structured-knowledge, user-preference, high

## Task
Store Obsidian writing format rule

## Result
When writing to Obsidian, create structured markdown notes, group them by topic or date, summarize instead of dumping raw chat, link related notes when possible, and organize daily memory notes with sections such as key decisions, technical notes, and user preferences.

## Lessons
- Use structured markdown for Obsidian memory.
- Group memory by topic or date.
- Summarize raw chat into durable knowledge.
- Link related notes when possible.
